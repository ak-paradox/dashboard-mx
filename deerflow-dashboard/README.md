# Deerflow AIoT Dashboard

Studio-lit 12-tile AIoT board converted from the Deerflow / Henryry reference. Dark tiles on a cream cyclorama (reference) and a paired light theme.

- Design tokens, type, and HTML layout: [DESIGN.md](./DESIGN.md)
- Interactive colour theme + layout: [design.html](./design.html)

## Quick start

```bash
npm install
npm run dev
```

| URL | What |
|-----|------|
| http://localhost:5176/ | Live dashboard (moon/sun theme toggle) |
| http://localhost:5176/design.html | Colour theme, type, HTML layout, interactions |
