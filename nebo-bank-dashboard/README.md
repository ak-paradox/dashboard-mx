# NEBO.Bank Dashboard

Dark + light neumorphic fintech dashboard converted from the NEBO.Bank UI reference.

- Design tokens & components: [DESIGN.md](./DESIGN.md)
- Interactive design aspects: [design.html](./design.html)

## Quick start

```bash
npm install
npm run dev
```

| URL | What |
|-----|------|
| http://localhost:5175/ | Live dashboard (moon/sun theme toggle) |
| http://localhost:5175/design.html | Design system & interaction demos |
